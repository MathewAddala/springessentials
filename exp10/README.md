# Student Manager

A React application for managing a list of students using the useState hook. Users can add new students, view the list in a table, and delete students dynamically without page refresh.

## Features

- Add students with ID, name, and course
- Display students in a table
- Delete students instantly
- Clean UI with basic styling

## Getting Started

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Open [http://localhost:5173](http://localhost:5173) in your browser

## Build

To build for production: `npm run build`
